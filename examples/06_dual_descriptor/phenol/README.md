# Dual Descriptor — Phenol

Δf(r) = f⁺(r) − f⁻(r) from the Fukui functions of phenol.
Blue (Δf > 0) marks nucleophilic sites; red (Δf < 0) electrophilic.

![](render.png)

## Files

- `DD.cub` — dual descriptor cube (from Multiwfn)
- `render.png` — the result

## Reproduce

1. Analysis → **Dual Descriptor**
2. Volumetric → **Load Cube…** → `DD.cub`
3. Render
